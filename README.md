# محل التوكيل لخدمات المحمول

صفحة روابط متجاوبة جاهزة لـ GitHub Pages أو Netlify.

استبدل الروابط التجريبية داخل `index.html` بروابط الحسابات الحقيقية.

## GitHub Pages
ارفع `index.html` إلى Repository، ثم Settings → Pages → Deploy from a branch → main → / (root).

## Netlify
ارفع مجلد المشروع إلى Netlify أو اربطه بمستودع GitHub.
